# Agent instructions

This public repository is a Next.js, Directus Sync and Qdrant demo designed for parallel work with coding agents.

## Safety and privacy

- Never commit `.env` files, credentials, tokens, local absolute paths, database data, uploads, Qdrant storage or machine-specific configuration.
- Commit only `api/.env.example` for environment documentation, using safe placeholders.
- Treat all existing worktree changes as user-owned. Do not discard or overwrite unrelated edits.
- Use non-destructive verification. Back up local data before a reset, drop or forced migration.

## Source of truth

- Directus structure: `api/directus-config/snapshot/`
- Directus permissions and settings: `api/directus-config/collections/`
- Demo blog content: `api/directus-config/seed/`
- Next.js application: `app/`
- Worktree and lifecycle commands: `bin/`

Next.js must consume published blog posts from Directus. Qdrant must remain a derived search index, rebuilt with `pnpm search:index`.

## Required project skills

Read the matching canonical skill before acting:

- Schema, fields, permissions or seed changes: `.agents/skills/directus-schema/SKILL.md`
- Creating, planning, splitting, reviewing or closing GitHub issues: `.agents/skills/issue-planning/SKILL.md`
- Parallel agents, worktrees, isolated stacks or destructive experiments: `.agents/skills/parallel-worktrees/SKILL.md`

## Worktrees

Substantive parallel tasks run in separate Git worktrees. Every worktree must have a unique `COMPOSE_PROJECT_NAME` and non-zero port offset generated by `bin/env.instance.command.sh`. Do not share a running stack or bind-mounted data between agents.

When assigning parallel work, give each agent exact file ownership, expected evidence and verification commands. Avoid overlapping files.

## Checks

Run checks proportional to the change. Before publishing the full project, run `pnpm verify` and the privacy scan documented in `README.md`.

Keep this file and `AGENTS.md` semantically identical when project guidance changes. `GEMINI.md` imports `AGENTS.md`, and Gemini CLI discovers the canonical `.agents/skills` directory directly.
